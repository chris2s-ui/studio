moltiplicazioni

La moltiplicazione è l'operazione aritmetica che formalizza l'idea di ripetizione, scalatura e proporzione. Nasce come un'abbreviazione dell'addizione ripetuta, ma si sviluppa fino a diventare uno degli strumenti algebrici più potenti per calcolare superfici, combinazioni e trasformazioni geometriche.

Dal punto di vista algebrico, la moltiplicazione è un'operazione binaria che associa a due numeri, detti fattori (nello specifico moltiplicando e moltiplicatore), un unico risultato chiamato prodotto. La sua struttura si regge su proprietà fondamentali:

Commutativa: l'ordine dei fattori non altera il prodotto (a x b = b x a).

Associativa: la raggruppabilità di tre o più fattori è indifferente (a x (b x c) = (a x b) x c).

Elemento neutro: l'unità ($1$) lascia invariato qualsiasi valore (a x 1 = a).

Elemento assorbente: la moltiplicazione per zero dà sempre zero (a x 0 = 0).

Distributiva rispetto all'addizione: connette la moltiplicazione all'addizione (a x (b + c) = a x b + a x c).
